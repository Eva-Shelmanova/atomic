Готовые .docx и .pdf хранятся в git (D-045) и пересобираются из исходников:

```bash
cd reports/tools && npm install          # один раз (пакет docx)
node build-stageA.js                     # контрольная точка этапа A
node build-report.js                     # отчёт по ГОСТ 7.32 (ссылки [@ключ] нумеруются по первому упоминанию, источники — refs.js)
node build-fullreport.js                 # подробный отчёт
uv run --with matplotlib python figs.py ../src   # рисунки (при изменении схем)
python3 to_pdf.py ../*.docx              # PDF рядом с .docx (LibreOffice; оглавление пересчитывается макросом)
```

Разметка исходников описана в начале `tools/gost.js`: `#*` — структурный элемент, `#`/`##` — разделы, `@table#id` и `{tab:id}` — таблица и ссылка на неё, `@figure`, `@toc` и т. д.

После открытия .docx в Word: согласиться на обновление полей (или выделить всё и нажать F9), чтобы заполнилось оглавление; в PDF оглавление уже с номерами страниц. Разбивка на страницы в Word может немного отличаться от PDF (LibreOffice). В отчёте по ГОСТ вручную: вставить копию подписанного задания на второй странице (в .docx и затем пересохранить PDF).
