# Документы для сдачи

| Файл | Что это | Исходник |
|---|---|---|
| `Этап A — описание модели данных и методов.docx` | контрольная точка этапа A (31.10.2026) | `src/stage-A-checkpoint.md` |
| `Отчёт по производственной практике (ГОСТ 7.32).docx` | отчёт по практике, ГОСТ 7.32-2017 | `src/practice-report.md` |
| `Полный отчёт по проекту (6 семестр – заморозка).docx` | подробный отчёт простым языком | `../docs/full-report.md` |

Файлы .docx в git не хранятся (D-002) — пересобираются из исходников:

```bash
cd reports/tools && npm install          # один раз (пакет docx)
node build-stageA.js                     # контрольная точка этапа A
node build-report.js                     # отчёт по ГОСТ 7.32 (ссылки [@ключ] нумеруются по первому упоминанию, источники — refs.js)
node build-fullreport.js                 # подробный отчёт
uv run --with matplotlib python figs.py ../src   # рисунки (при изменении схем)
```

Разметка исходников описана в начале `tools/gost.js`: `#*` — структурный элемент, `#`/`##` — разделы, `@table#id` и `{tab:id}` — таблица и ссылка на неё, `@figure`, `@toc` и т. д.

После открытия в Word: согласиться на обновление полей (или выделить всё и нажать F9), чтобы заполнилось оглавление с номерами страниц. В отчёте по ГОСТ вручную: вставить копию подписанного задания на второй странице и указать число страниц в реферате («Отчёт __ с.»).
