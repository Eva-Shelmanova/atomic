Справка по сценарию LOCAC — течь теплоносителя, холодная нитка.
Источник: журналы событий симулятора PCTRAN (файлы «Transient Report») обучающих прогонов набора NPPAD (thu-inet, коммит a8d54ed; число прогонов — 60, тяжесть 1–100 % от 100 см²). Справка построена автоматически скриптом scripts/build_scenario_kb.py; val- и test-прогоны не использовались.

Типичная последовательность действий систем станции после ввода неисправности (доля прогонов; медиана и межквартильный размах времени от ввода):
- сигнал АЗ по низкому давлению первого контура — 97 % прогонов; 128 с (120 с–149 с)
- аварийная остановка реактора (срабатывание АЗ) — 100 % прогонов; 130 с (120 с–152 с)
- запуск высоконапорного впрыска САОЗ по низкому давлению первого контура — 92 % прогонов; 136 с (126 с–153 с)
- включение насосов высоконапорного впрыска — 100 % прогонов; 137 с (126 с–162 с)
- закрытие клапана вентиляции защитной оболочки — 100 % прогонов; 137 с (126 с–162 с)
- включение насосов спринклерной системы — 100 % прогонов; 180 с (148 с–259 с)
- запуск спринклерной системы защитной оболочки — 100 % прогонов; 180 с (148 с–259 с)
- закрытие отсечных клапанов питательной воды — 77 % прогонов; 313 с (227 с–14 мин)
- сигнал отсечения питательной воды по низкой температуре теплоносителя — 77 % прогонов; 313 с (227 с–14 мин)
- оголение активной зоны — 45 % прогонов; 14 мин (11 мин–21 мин)
- открытие клапанов гидроёмкостей САОЗ — 45 % прогонов; 29 мин (18 мин–39 мин)
- переход на рециркуляцию из приямка по уровню в баке запаса воды — 98 % прогонов; 49 мин (48 мин–50 мин)

Аварийная остановка реактора происходит в 100 % прогонов сценария LOCAC.
